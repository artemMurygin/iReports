Создаёт услуги в RemOnline для всех строк, где в столбце ID (E) указано «Создать».

Обязательные поля: Тип устройства (G), Модель устройства (H), Качество запчасти (I), Наименование услуги (J), Категория (K, формат: Категория > Подкатегория > ... > Последняя), Срок гарантии (L), Период гарантии (M: «дн.» или «мес.»), Начисление мастеру (BU), Цена услуги (AY).
Необязательно: Номер модели (N).

Название услуги: [Наименование] [Тип устройства] [Модель устройства] [Качество запчасти] ([Номер модели]).

После обработки в столбец ID записывается ID созданной услуги либо «ОШИБКА: ...» с описанием проблемы.
