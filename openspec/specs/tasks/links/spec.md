## Purpose

Задача может иметь одну или несколько ссылок на внешние материалы (результат работы, документ,
обсуждение и т.п.), которые видны и управляются прямо в карточке задачи.

## Requirements

### Requirement: Задача может иметь несколько ссылок
Задача SHALL поддерживать произвольное число ссылок (ноль, одну или несколько). Каждая ссылка
SHALL сохранять адрес и, опционально, подпись. Все ссылки задачи SHALL быть видны в её карточке.

#### Scenario: Первая ссылка добавляется к задаче без ссылок
- **WHEN** пользователь добавляет ссылку к задаче, у которой ещё нет ни одной ссылки
- **THEN** ссылка сохраняется и отображается в карточке задачи

#### Scenario: К задаче добавляется ещё одна ссылка
- **WHEN** пользователь добавляет ссылку к задаче, у которой уже есть одна или несколько ссылок
- **THEN** новая ссылка добавляется к уже существующим, ни одна из прежних ссылок не теряется

#### Scenario: Задача без ссылок не показывает список ссылок
- **WHEN** открывается карточка задачи, к которой не добавлено ни одной ссылки
- **THEN** список ссылок в карточке задачи пуст

### Requirement: Ссылка удаляется из карточки задачи
Пользователь SHALL иметь возможность удалить ранее добавленную ссылку прямо в карточке задачи.

#### Scenario: Удаление ссылки
- **WHEN** пользователь удаляет одну из ссылок задачи
- **THEN** ссылка больше не отображается в карточке задачи, остальные ссылки задачи не затрагиваются

### Requirement: Ссылка должна быть валидным адресом
Система SHALL отклонять добавление ссылки, значение которой не является синтаксически валидным URL.

#### Scenario: Невалидная ссылка отклоняется
- **WHEN** пользователь пытается добавить ссылку со значением, которое не является синтаксически
  валидным URL
- **THEN** ссылка не сохраняется, пользователю сообщается об ошибке
