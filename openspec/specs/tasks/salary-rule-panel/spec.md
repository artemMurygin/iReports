## Purpose

Карточка задачи показывает связанное зарплатное правило и начисление, которое отображается за эту
задачу, и позволяет открыть боковую панель с описанием правила, не покидая карточку задачи.

## Requirements

### Requirement: Карточка задачи показывает связанное зарплатное правило
Если на задачу ссылается зарплатное правило «за выполнение задачи» (текущего расчётного периода),
карточка задачи SHALL показывать блок с этим правилом. Если ни одно правило не ссылается на задачу,
карточка SHALL не показывать этот блок.

#### Scenario: Задача, на которую ссылается правило, показывает блок правила
- **WHEN** открывается карточка задачи, на которую ссылается зарплатное правило «за выполнение
  задачи»
- **THEN** карточка задачи показывает блок со связанным правилом

#### Scenario: Задача без связанного правила не показывает блок
- **WHEN** открывается карточка задачи, на которую в текущем расчётном периоде не ссылается ни одно
  зарплатное правило
- **THEN** блок связанного правила в карточке задачи не отображается

### Requirement: Карточка задачи показывает начисление за задачу
Если по связанному зарплатному правилу уже отображается начисление за эту задачу (см.
`service/accounting#Requirement: Правило «за выполнение задачи» не видно в прогнозе до выполнения`,
`shop/accounting#Requirement: Правило «за выполнение задачи» не видно в прогнозе до выполнения`),
карточка задачи SHALL показывать это начисление. Пока начисление за задачу недоступно, карточка SHALL
показывать связанное правило без данных начисления.

#### Scenario: Начисление за выполненную задачу видно на её карточке
- **WHEN** задача переведена в статус «Закрыта успешно» и по связанному правилу уже отображается
  начисление за эту задачу
- **THEN** карточка задачи показывает это начисление рядом со связанным правилом

#### Scenario: До выполнения задачи начисление не показывается
- **WHEN** задача, на которую ссылается зарплатное правило, ещё не переведена в статус «Закрыта
  успешно»
- **THEN** карточка задачи показывает связанное правило без данных начисления

### Requirement: Клик по связанному правилу открывает боковую панель с его описанием
Клик по блоку связанного зарплатного правила на карточке задачи SHALL открывать боковую панель того
же вида, что и карточка задачи, содержащую описание правила (вид правила, направление, параметры
правила), без перехода на отдельную страницу и без закрытия карточки задачи «под» панелью правила.

#### Scenario: Открытие панели правила из карточки задачи
- **WHEN** пользователь на карточке задачи нажимает на блок связанного зарплатного правила
- **THEN** открывается боковая панель с описанием этого правила

#### Scenario: Закрытие панели правила возвращает к карточке задачи
- **WHEN** пользователь закрывает открытую боковую панель зарплатного правила
- **THEN** пользователь снова видит карточку задачи, из которой была открыта панель правила
