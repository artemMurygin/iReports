## Why

Закупочные цены магазина обновляются из XLSX-прайса поставщика вручную: сотрудник скачивает файл и загружает его через сайдбар Google Sheets. Это ежедневная рутина, которую легко забыть. Прайс лежит в известной папке Google Drive, поэтому выгрузку можно запускать автоматически, а сотрудников оповещать только о результате.

## What Changes

- Новый cron: в 12:00 по будням (Пн–Пт) бэкенд берёт единственный файл (Excel или Google-таблицу, которую редактируют на месте) из папки Google Drive `1lum1VoyWmlIDevHw4Qox5jnlUHrID5Z4`.
- Если название файла изменилось с момента последней успешной выгрузки (при обновлении прайса название меняется), файл скачивается (Google-таблица — экспортом в XLSX) и передаётся (base64) в существующую команду `StartPriceImportCommand` (`domains/shop/modules/marketing/pricing`). Пайплайн импорта не меняется.
- Если файл не изменился — импорт не запускается, в Telegram уходит уведомление: прайс не обновился, сотрудникам нужно самим следить за обновлением прайса и загружать его вручную.
- Если файл не найден в папке или импорт завершился ошибкой — в Telegram уходит уведомление об ошибке.
- Если импорт завершён успешно — в Telegram уходит короткое уведомление «прайс-лист выгружен», без деталей (счётчиков сопоставления и т.п.).
- Новая интеграция с Telegram: бот отправляет сообщения в группу. Токен бота — в env, `chat_id` группы — в конфиге.
- Доступ к Drive — через тот же сервисный аккаунт Google, что и у Google Sheets (`GOOGLE_SERVICE_ACCOUNT_EMAIL`/`GOOGLE_PRIVATE_KEY`); ему нужен дополнительный read-only scope Drive, а папка должна быть расшарена на этот аккаунт.
- Ручная выгрузка через сайдбар и существующие эндпоинты `import-costs` остаются без изменений.

## Impact

- **Код (backend):** `domains/shop/modules/marketing/pricing` — cron-триггер, порт получения файла прайса, порт нотификаций, хранение названия последнего успешно выгруженного файла; новая интеграция `src/integrations/telegram`; расширение `src/integrations/google-sheets` (или отдельная Drive-интеграция) на скачивание файла из Drive.
- **Конфигурация:** env `TELEGRAM_BOT_TOKEN`; `chat_id` группы и id папки Drive — в конфиге; scope `drive.readonly` у сервисного аккаунта; доступ сервисного аккаунта к папке.
- **Зависимости:** используется уже подключённый `googleapis` (Drive API); отдельный Telegram-SDK не обязателен (Bot API по HTTP).
- **Инфраструктура:** cron работает только при `ENABLE_CRON=true` (`ProdCron`), как остальные синхронизации.
- **Не затрагивается:** контракты `ireports-contracts`, фронтенд, `sheets-app`, HTTP-эндпоинты.
