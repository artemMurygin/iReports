## MODIFIED Requirements

### Requirement: Виды зарплатных правил
Зарплатное правило SHALL быть одного из четырёх видов: почасовая оплата, оплата за выполненную
услугу, вознаграждение за оплаченный заказ, оплата за выполнение задачи.

#### Scenario: Почасовая оплата считается по отработанным часам
- **WHEN** правило сотрудника — почасовая оплата
- **THEN** начисление за период рассчитывается по количеству отработанных часов за этот период

#### Scenario: Оплата за услугу считается по факту выполнения
- **WHEN** правило сотрудника — оплата за выполненную услугу
- **THEN** начисление рассчитывается по услугам, выполненным сотрудником за период

#### Scenario: Вознаграждение за заказ считается по факту оплаты
- **WHEN** правило сотрудника — вознаграждение за оплаченный заказ
- **THEN** начисление рассчитывается по заказам, оплаченным за период

#### Scenario: Оплаченность заказа определяется его статусом, а не накопленной суммой
- **WHEN** определяется, считается ли заказ оплаченным для расчёта вознаграждения
- **THEN** решение принимается по тому, к какой группе статусов заказа он относится, а не по факту
  наличия ненулевой накопленной оплаты по заказу

#### Scenario: Оплата за выполнение задачи считается по статусу связанной задачи
- **WHEN** правило сотрудника — оплата за выполнение задачи
- **THEN** начисление по правилу доступно только после того, как связанная с правилом задача
  переведена в статус «Закрыта успешно»

### Requirement: Правило «за выполнение задачи» не видно в прогнозе до выполнения
Пока связанная задача не переведена в статус «Закрыта успешно», строка по правилу «за выполнение
задачи» SHALL отсутствовать как в фактическом, так и в прогнозном режиме зарплатного отчёта
сотрудника. Промежуточные статусы задачи (в т.ч. «Выполнена» — заявление ответственного, ещё не
принятое руководителем) на видимость строки не влияют — строка появляется только после статуса
«Закрыта успешно».

#### Scenario: Прогнозный отчёт не содержит строку невыполненного правила
- **WHEN** зарплатный отчёт сотрудника за период запрашивается в прогнозном режиме, а связанная
  задача правила ещё не в статусе «Закрыта успешно»
- **THEN** строка по этому правилу отсутствует в отчёте

#### Scenario: Фактический отчёт не содержит строку невыполненного правила
- **WHEN** зарплатный отчёт сотрудника за период запрашивается в фактическом режиме, а связанная
  задача правила ещё не в статусе «Закрыта успешно»
- **THEN** строка по этому правилу отсутствует в отчёте

#### Scenario: Задача в статусе «Выполнена», ещё не принятая руководителем, не показывает строку
- **WHEN** ответственный сотрудник перевёл задачу в статус «Выполнена», но руководитель ещё не
  закрыл её как успешную
- **THEN** строка по этому правилу отсутствует в отчёте

#### Scenario: Оба режима отчёта показывают строку после выполнения задачи
- **WHEN** связанная задача правила переведена в статус «Закрыта успешно»
- **THEN** строка по этому правилу появляется как в фактическом, так и в прогнозном режиме отчёта за
  период, к которому относится задача
