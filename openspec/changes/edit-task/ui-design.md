# UI Design: edit-task

## Источник дизайна
- **.pen файл**: `design/sallary-first-iteration.pen`
- **UI Kit**: фрейм `uDEum` в этом же файле — переиспользуемые компоненты (кнопки, инпуты, карточки, KPI, таблицы, чипы, бейджи и т.д.)

**Решение пользователя (2026-09-15)**: отдельный Pencil-макет для этого change НЕ создавался.
architecture.md не заводит новых/изменённых Pages — изменение целиком укладывается в уже
существующую карточку задачи (Pencil-фрейм `Q7v9pt`, «Панель · Детализация задачи», см. WHY-комментарий
в `features/TaskStatusControl/ui/TaskStatusCard.tsx`). Вместо визуальной итерации в Pencil
режим редактирования визуально копирует уже утверждённый и реализованный паттерн формы
`features/CreateTask/ui/CreateTaskForm.tsx` (те же `Input`/`Textarea`/`Select` из
`shared/ui-kit/atoms`, тот же `gap`/`label`-стиль) — так же, как и остальные вставки внутри
`TaskStatusCard` (переходы статуса, ссылки, комментарии) уже переиспользуют `shared/ui-kit`
напрямую, без отдельного Pencil-фрейма на каждое такое расширение.
