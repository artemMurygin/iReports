# UI Design: delete-motivation-schema

_Pencil-макеты пропущены по решению пользователя: фича — одна кнопка «Удалить схему» в уже
существующем `PageHeader` + модалка подтверждения, дословно повторяющая уже реализованный и
провалидированный на реальных экранах паттерн (`DeletePayoutDialog`, `DeleteIdentityModal`), без
новых визуальных решений. Ниже — текстовое описание вместо артбордов._

## Источник переиспользуемых компонентов (код, не Pencil)

- `shared/ui-kit/atoms/Button` (`variant="danger"`, `variant="ghost"`) — уже используется в `PageHeader.tsx` и в `DeletePayoutDialog`.
- `shared/ui-kit/organisms/Modal` — те же `open`/`onOpenChange`/`title`/`footer`/`children`, что в `DeletePayoutDialog`/`DeleteIdentityModal`.
- Иконки `lucide-react`: `Trash2` (кнопка удаления/подтверждение), `Loader2` (pending), `RotateCw` (повторить после ошибки), `CircleX` (инлайн-ошибка в `bg-danger-soft`).

## Ключевые состояния экранов

| Экран                                                     | Состояние                          | Как показано                                                                                                         |
| -------------------------------------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `DeleteMotivationSchemaDialog` (открыт)                    | idle (ожидание подтверждения)          | `Modal` с заголовком «Удалить схему «{schemaName}»?», текстом-предупреждением («Все правила схемы будут удалены безвозвратно. Действие нельзя отменить.») и кнопками «Отмена»/«Удалить» — тот же вид, что `DeletePayoutDialog`. |
| `DeleteMotivationSchemaDialog`                              | pending (запрос выполняется)           | Кнопка «Удалить» → `Loader2` + «Удаляем…», кнопки задизейблены, закрытие модалки во время pending заблокировано (как в `DeletePayoutDialog.handleOpenChange`). |
| `DeleteMotivationSchemaDialog`                              | error (сервер вернул ошибку)           | Инлайн-блок `bg-danger-soft` с `CircleX` и текстом ошибки; кнопка «Удалить» → `RotateCw` + «Повторить» (без закрытия модалки). |
| `SalaryRuleDetail` после успешного удаления                | success                                | `navigate()` на список схем (`SalaryRuleList`) того же направления; инвалидация `['salary-rule-list']` гарантирует, что удалённая схема не появится в списке из кеша. |
