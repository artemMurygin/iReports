## ADDED Requirements

### Requirement: Удаление мотивационной схемы направления «Сервис»
Пользователь SHALL иметь возможность полностью удалить мотивационную схему направления «Сервис» по
её идентификатору. Удаление необратимо — soft-delete не поддерживается. Удаление схемы одного
направления SHALL не затрагивать правила или имя другого направления той же физически общей строки
`motivation_schemas`; родительская строка SHALL удаляться только когда после удаления правил своего
направления у неё не осталось правил другого направления.

#### Scenario: Удаление схемы по id
- **WHEN** пользователь запрашивает удаление мотивационной схемы направления «Сервис» по
  существующему id
- **THEN** схема и все её зарплатные правила направления «Сервис» удаляются безвозвратно

#### Scenario: Удаление не затрагивает правила другого направления той же общей строки
- **WHEN** удаляется мотивационная схема направления «Сервис», а физически общая строка также
  содержит правила направления «Магазин»
- **THEN** правила и имя направления «Магазин» остаются нетронутыми, родительская строка не
  удаляется
