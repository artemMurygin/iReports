## ADDED Requirements

### Requirement: Удаление задачи через интерфейс
Пользователь SHALL иметь возможность безвозвратно удалить задачу из карточки задачи в интерфейсе
iReports, независимо от текущего статуса задачи (включая терминальные статусы «Закрыта успешно» и
«Закрыто неуспешно»). Перед удалением интерфейс SHALL запросить подтверждение действия, явно
предупредив о его безвозвратности. После подтверждения удалённая задача SHALL немедленно исчезнуть
из списка задач и из карточки деталей задачи.

#### Scenario: Пользователь подтверждает удаление задачи
- **WHEN** пользователь нажимает «Удалить» на карточке задачи и подтверждает действие в диалоге
- **THEN** задача безвозвратно удаляется, карточка деталей задачи закрывается, задача пропадает из
  списка задач

#### Scenario: Пользователь отменяет удаление
- **WHEN** пользователь открывает диалог подтверждения удаления задачи, но нажимает «Отмена» или
  закрывает диалог, не подтвердив действие
- **THEN** задача не удаляется, карточка задачи остаётся открытой без изменений

#### Scenario: Удаление доступно для задачи в терминальном статусе
- **WHEN** пользователь удаляет задачу, уже находящуюся в статусе «Закрыта успешно» или «Закрыто
  неуспешно»
- **THEN** задача удаляется так же, как и задача в любом другом статусе
