## Purpose

Описывает поведение read-only каталога категорий магазина: дерево категорий, отдаваемое по запросу
для отображения в UI. Единственная реализованная на сегодня часть целевого набора складских модулей
(`purchasing`/`logistics`/`warehouse`, см. `domains/shop/CLAUDE.md`) — не покрывает остатки, резервы
или движение товара, только структуру справочника категорий.

## ADDED Requirements

### Requirement: Дерево категорий строится из уже синхронизированного справочника
Дерево категорий каталога SHALL строиться из уже синхронизированных данных справочника категорий
МойСклад, без обращения к самой ERP-системе и без запуска дополнительной синхронизации.

#### Scenario: Пустой справочник — пустое дерево
- **WHEN** локальный справочник категорий пуст
- **THEN** запрос дерева категорий возвращает пустой список, а не ошибку

#### Scenario: Несколько уровней вложенности собираются в дерево, а не в плоский список
- **WHEN** в справочнике есть категории с отношением «родитель — потомок» на нескольких уровнях
  вложенности
- **THEN** результат представляет собой дерево, где каждый узел содержит вложенный список своих
  непосредственных потомков, а не плоский список всех категорий

### Requirement: Архивные категории не исключаются из дерева
Категория, помеченная в справочнике как архивная, SHALL оставаться в дереве наравне с активными
категориями.

#### Scenario: Архивная категория видна как потомок родителя
- **WHEN** среди потомков категории есть категория, помеченная архивной
- **THEN** архивная категория присутствует в списке потомков наравне с неархивными

### Requirement: Дерево строится одним запросом к справочнику
Построение дерева категорий SHALL выполняться одним запросом к хранилищу справочника, независимо от
числа категорий и глубины вложенности — сборка иерархии из плоского результата SHALL происходить в
памяти, а не дополнительными запросами на каждый уровень.

#### Scenario: Число запросов к справочнику не зависит от глубины дерева
- **WHEN** запрашивается дерево категорий, независимо от того, сколько в справочнике категорий и
  насколько глубоко они вложены
- **THEN** к хранилищу справочника выполняется ровно один запрос
