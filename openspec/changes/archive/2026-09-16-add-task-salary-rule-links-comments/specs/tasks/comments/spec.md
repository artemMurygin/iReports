## Purpose

Пользователи могут оставлять комментарии к задаче — с указанием автора, времени и текста сообщения —
чтобы фиксировать обсуждение и пояснения рядом с задачей, не полагаясь на внешние каналы связи.

## ADDED Requirements

### Requirement: Комментарий фиксирует автора, время и текст
Комментарий к задаче SHALL сохранять автора (оставившего его сотрудника), момент создания и текст
сообщения. Карточка задачи SHALL показывать все комментарии задачи в хронологическом порядке (от
самого старого к самому новому), для каждого — автора, время и текст.

#### Scenario: Комментарий добавляется к задаче без комментариев
- **WHEN** сотрудник оставляет первый комментарий к задаче
- **THEN** комментарий сохраняется с указанием автора и времени и отображается в карточке задачи

#### Scenario: Новый комментарий добавляется к уже существующим
- **WHEN** сотрудник оставляет комментарий к задаче, у которой уже есть один или несколько
  комментариев
- **THEN** новый комментарий отображается последним в хронологическом списке, ни один из прежних
  комментариев не теряется

#### Scenario: Задача без комментариев не показывает список комментариев
- **WHEN** открывается карточка задачи, к которой ещё не оставлено ни одного комментария
- **THEN** список комментариев в карточке задачи пуст

### Requirement: Комментарии видны каждому, кто открывает карточку задачи
Любой пользователь, открывший карточку задачи, SHALL видеть все комментарии этой задачи —
независимо от того, кто их оставил.

#### Scenario: Другой сотрудник видит уже оставленные комментарии
- **WHEN** сотрудник, не оставлявший ни одного комментария к задаче, открывает её карточку
- **THEN** он видит все комментарии, оставленные другими сотрудниками, вместе с их авторами и
  временем

### Requirement: Пустой комментарий отклоняется
Система SHALL отклонять добавление комментария, текст которого пуст или состоит только из пробельных
символов.

#### Scenario: Попытка оставить пустой комментарий отклоняется
- **WHEN** пользователь пытается добавить комментарий без текста или состоящий только из пробелов
- **THEN** комментарий не сохраняется, пользователю сообщается об ошибке
