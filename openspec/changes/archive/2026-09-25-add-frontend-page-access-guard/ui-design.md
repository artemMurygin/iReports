## Почему без Pencil/новых экранов

Изменение не добавляет и не переверстывает ни одного экрана: `AccessDeniedPage` (экран «нет
доступа») уже существует и используется `RouteGuard` для `settings/roles`/`work-schedule` — этот
change лишь подключает его к большему числу роутов (см. architecture.md, «Затронутые роуты»).
Единственное затрагиваемое место с визуальным эффектом — пункты меню в `Header`/`NavDrawer`,
которые для пользователя без прав просто не рендерятся (тот же паттерн, что уже применяется к
`disabled: true` — полное исчезновение пункта, не новое состояние компонента). Ни один компонент
UI Kit не меняется и не создаётся, новых breakpoint'ов/состояний нет — дизайнировать в
`design/sallary-first-iteration.pen` нечего.
